Accelerating CNN Inference on a GPU

Every way a CNN's forward pass gets run on an NVIDIA GPU, from a naive CUDA kernel to a production TensorRT engine. Implemented from scratch, checked against a CPU reference, and profiled to explain which approach wins in which regime, and why.

No single winner

At one channel my tiled kernel beats cuDNN. By 64 channels cuDNN is ~25× faster. The fastest implementation depends on the shape of the problem.

Reformulate, don't micro-optimize

The way past a hand-written kernel wasn't a cleverer kernel. It was turning the convolution into a matrix multiply. im2col + cuBLAS ran ~10× faster than naive.

FP16 isn't free speed

Half precision only helps when the Tensor Cores actually engage. In TensorRT it was 5× faster than PyTorch. In raw cuDNN, sometimes slower than FP32.
